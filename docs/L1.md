## แบบฝึกหัด: ./mvnw dependency:tree

| library / starter | มีไว้ทำอะไร |
|---|---|
| Spring Boot | จัดการและตั้งค่าระบบสำหรับการทดสอบอัตโนมัติ |
| Spring Framework | จัดการ Bean, Dependency Injection และส่วนประกอบพื้นฐานของ Spring |
| Logback / SLF4J / Log4j | แสดง Log เพื่อตรวจสอบการทำงานและข้อผิดพลาดของโปรแกรม |
| JUnit | เขียนและรัน Unit Test เพื่อตรวจสอบความถูกต้องของโปรแกรม |
| Mockito | สร้าง Mock Object เพื่อจำลองการทำงานของส่วนอื่นโดยไม่ต้องเชื่อมต่อระบบจริง |
| AssertJ / Hamcrest | ตรวจสอบว่าผลลัพธ์ที่ได้ตรงตามที่คาดหวังหรือไม่ |
| JSONPath / JSONassert / JSON-smart | อ่าน ค้นหา และตรวจสอบข้อมูล JSON |
| Awaitility | รอและตรวจสอบเงื่อนไขที่เกิดขึ้นแบบไม่พร้อมกัน |
| Byte Buddy / Objenesis | ช่วยสร้างและจัดการ Object สำหรับการทดสอบ |
| XMLUnit | เปรียบเทียบและตรวจสอบข้อมูล XML |
| SnakeYAML | อ่านและจัดการไฟล์ YAML |
| Micrometer | เก็บข้อมูลและติดตามการทำงานของระบบ |
| Jakarta Libraries | รองรับการจัดการ Annotation, XML และข้อมูลประเภทต่าง ๆ |

## Reflection (2–3 ประโยคต่อข้อ)

1. red bar แรกพิสูจน์อะไร ที่ green bar อย่างเดียวพิสูจน์ไม่ได้
   >Red bar แรกพิสูจน์ว่า Test สามารถตรวจจับข้อผิดพลาดได้จริง เมื่อโค้ดยังไม่ถูกแก้ไขหรือยังไม่มีการ Implement ฟังก์ชันตามที่กำหนด ทำให้มั่นใจได้ว่า Test ไม่ได้ผ่านโดยไม่มีเหตุผล และสามารถตรวจสอบความถูกต้องของโปรแกรมได้จริง
2. ถ้าเครื่องของคุณหายวันนี้ จะกู้งานกลับมาได้จากที่ไหน
    >สามารถกู้คืนงานได้จาก GitHub Repository ที่ใช้เก็บ Source Code และประวัติการแก้ไขโปรแกรม รวมถึงไฟล์สำรองที่จัดเก็บไว้บน Cloud ทำให้สามารถ Clone โปรเจกต์กลับมาทำงานต่อบนเครื่องใหม่ได้ โดยไม่จำเป็นต้องเริ่มต้นเขียนโปรแกรมใหม่ทั้งหมด
